About Norfolk Terminal Directory

PWA Version 2.6 • Offline Enabled

This progressive web application provides field operators, dispatchers, and drivers with immediate access to industrial facility codes, operating hours, track/zone assignments, audit dates, and direct contact numbers across the Norfolk, Chesapeake, and Hampton Roads shipping terminals.

Quick Features

  • Instant searching by Code, Company, or Zone
  • Interactive Leaflet Map with GPS facility pins
  • Direct telephone dialing and clipboard sharing
  • Offline-ready caching via local storage
